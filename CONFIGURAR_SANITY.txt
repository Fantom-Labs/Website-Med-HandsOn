🎉 A integração do Sanity foi instalada com sucesso!

📝 PARA COMEÇAR A USAR, SIGA ESTES PASSOS:

1️⃣ CRIAR ARQUIVO .ENV.LOCAL
   Na raiz do projeto, crie um arquivo chamado: .env.local
   
   Cole este conteúdo dentro dele:
   ┌────────────────────────────────────────────────────────────┐
   │ NEXT_PUBLIC_SANITY_PROJECT_ID=""                           │
   │ NEXT_PUBLIC_SANITY_DATASET="production"                    │
   │ NEXT_PUBLIC_SANITY_API_VERSION="2024-11-27"                │
   └────────────────────────────────────────────────────────────┘

2️⃣ OBTER O PROJECT ID
   • Acesse: https://www.sanity.io/manage
   • Faça login (ou crie uma conta gratuita)
   • Clique em "Create New Project"
   • Nome sugerido: "Med HandsOn Blog"
   • Selecione o plano FREE
   • Copie o PROJECT ID (algo como: abc123xyz)
   • Cole entre as aspas no .env.local

3️⃣ RODAR O PROJETO
   npm run dev

4️⃣ ACESSAR O SANITY STUDIO
   Abra no navegador: http://localhost:3000/studio
   Faça login com sua conta Sanity

5️⃣ CRIAR PRIMEIRO POST
   • Clique em "Posts do Blog"
   • Clique em "Create"
   • Preencha os campos
   • Clique em "Publish"

6️⃣ VER O BLOG
   Acesse: http://localhost:3000/blog
