# 📝 Guia Rápido - Como Gerenciar o Blog

## 🎯 Acesso Rápido

### URL do Editor: `https://seusite.com/studio`

**Primeiro Acesso:**
1. Você receberá credenciais de acesso
2. Faça login com sua conta
3. Pronto! Já pode criar posts

---

## ✍️ Como Criar um Novo Post

### Passo a Passo

1. **Entrar no Studio**
   - Acesse `/studio`
   - Faça login

2. **Criar Novo Post**
   - Clique em **"Posts do Blog"** (menu lateral)
   - Clique no botão **"Create"** (ícone +)

3. **Preencher Informações Básicas**
   
   | Campo | Descrição | Exemplo |
   |-------|-----------|---------|
   | **Título** | Nome do artigo | "Rinoplastia: O que você precisa saber" |
   | **Slug** | URL do post (clique em Generate) | `rinoplastia-o-que-voce-precisa-saber` |
   | **Resumo** | Breve descrição (aparece nos cards) | "Descubra tudo sobre rinoplastia..." |

4. **Adicionar Imagem de Capa**
   - Clique em "Upload"
   - Escolha uma imagem (mínimo 1200x675px)
   - Ajuste o recorte se necessário

5. **Categorizar**
   - Escolha uma categoria:
     - 🔬 Cirurgia Plástica
     - 📚 Educação Médica
     - 💼 Carreira
     - 📰 Notícias

6. **Tempo de Leitura**
   - Digite quanto tempo leva para ler
   - Ex: "5 min de leitura"
   - Dica: ~200 palavras = 1 minuto

7. **Escrever o Conteúdo**
   - Use o editor visual
   - Veja formatação abaixo ⬇️

8. **Publicar**
   - Clique em **"Publish"**
   - Pronto! Artigo está no ar 🎉

---

## 🎨 Como Formatar o Conteúdo

### Títulos e Estilos

- **Normal**: Texto padrão do parágrafo
- **H2**: Título de seção principal
- **H3**: Subtítulo
- **H4**: Sub-subtítulo
- **Citação**: Para destacar frases importantes

### Formatação de Texto

| Botão | Função |
|-------|--------|
| **B** | Negrito |
| *I* | Itálico |
| U | Sublinhado |
| 🔗 | Link |

### Como Adicionar um Link

1. Selecione o texto
2. Clique no ícone de link (🔗)
3. Cole a URL
4. Clique em "Add"

### Listas

- **Lista com marcadores**: Para itens não ordenados
  - Item 1
  - Item 2
  - Item 3

- **Lista numerada**: Para passos ou sequências
  1. Primeiro
  2. Segundo
  3. Terceiro

### Adicionar Imagens no Meio do Texto

1. Clique no ícone **+** no editor
2. Escolha **"Image"**
3. Faça upload da imagem
4. Preencha:
   - **Texto Alternativo**: Descrição da imagem (acessibilidade)
   - **Legenda**: Texto que aparece abaixo da imagem (opcional)
5. Clique em "Insert"

## ✏️ Como Editar um Post Publicado

1. Acesse `/studio`
2. Clique em **"Posts do Blog"**
3. Clique no post que deseja editar
4. Faça as alterações
5. Clique em **"Publish"** novamente
6. ⏱️ Aguarde até 1 minuto - o site atualiza automaticamente

---

## 🗑️ Como Excluir um Post

1. Abra o post que deseja excluir
2. Clique no menu **⋮** (três pontos) no canto superior direito
3. Escolha **"Delete"**
4. Confirme a exclusão
5. ✅ Post removido do site

## 💡 Dicas de Ouro

### ✅ Para Imagens

| Tipo | Tamanho Recomendado |
|------|---------------------|
| Imagem de Capa | 1200 x 675px (proporção 16:9) |
| Imagens no Conteúdo | Largura máxima 800px |

**Dica:** Use imagens de alta qualidade e otimizadas (formato JPG ou PNG)

### ✅ Para Títulos

- ✓ Seja claro e direto
- ✓ Use palavras-chave importantes
- ✓ Máximo 60-70 caracteres
- ✗ Evite clickbait exagerado

### ✅ Para Resumos

- ✓ Máximo 200 caracteres
- ✓ Resuma o benefício do artigo
- ✓ Use linguagem convidativa
- ✗ Não copie o início do texto

### ✅ Para Slugs (URLs)

- ✓ Clique em "Generate" - é automático
- ✓ Use apenas palavras importantes
- ✓ Sem acentos, espaços ou caracteres especiais
- ✓ Exemplo: `rinoplastia-ultrassonica`

### ✅ Para Conteúdo

- ✓ Parágrafos curtos (3-4 linhas)
- ✓ Use subtítulos (H3, H4) para organizar
- ✓ Adicione listas quando possível
- ✓ Inclua imagens a cada 3-4 parágrafos
- ✓ Termine com call-to-action (ex: "Entre em contato")

## 🆘 Problemas Comuns

### "Não consigo publicar"
→ Verifique se todos os campos obrigatórios estão preenchidos (estrela vermelha)

### "Imagem não aparece no site"
→ Aguarde 1 minuto. Se não resolver, recarregue a página com Ctrl+F5

### "Esqueci minha senha"
→ Na tela de login, clique em "Forgot password" e siga as instruções

### "Post está diferente do que escrevi"
→ Clique em "Publish" novamente. Aguarde 1 minuto e recarregue a página.
